# 个人作品集 Demo 功能完整版修订

## 目标

在不修改网站源码、视觉设计和生产功能的前提下，重新生成作品集演示视频与静态 PDF 展示册。

## 视频

- 保持 1920 x 1080、30 fps、H.264 视频与 AAC 立体声音频。
- 保留录制专用鼠标指针与点击反馈，但不写入网站源码。
- 个人能力档案展开后，鼠标必须依次点击每一个雷达节点。
- 每个能力节点点击后必须停留到标题、评分和具体描述清晰可见。
- 公众号“笑不忘书”必须展示长图阅读和上一页/下一页切换，并让页码变化可见。
- 片尾停留在联系方式与动态名片页面，不再增加二维码片尾。
- 不添加后期字幕。
- 成品覆盖原 Vercel Blob 文件名，保持现有永久 URL 和二维码内容不变。

## PDF

PDF 采用功能完整版，不限制为 10 页，不追求逐张素材全量收录。

- 每页为一张完整 16:9 网站状态截图，不增加演示模板、字幕或装饰框。
- 覆盖 Hero、个人优势、全部能力节点详情和主要个人经历。
- 覆盖设计类全部类别入口，并展示代表性的图库切换状态。
- 覆盖视频入口、电影票选择、视频首帧与播放器控制状态。
- 覆盖文案类全部文件夹入口，并展示代表性的阅读栏顶部和下滑状态。
- 覆盖运营类锁屏、解锁主页、三个 App 入口、公众号账号入口、账号作品浏览、长图翻页和下滑状态。
- 覆盖联系方式、邮箱复制反馈与邮箱入口弹窗。
- 页数预计 35-50 页，以主要功能和交互状态完整为准。

## 交付与清理

- 最终交付 MP4、PDF、PPTX、二维码 PNG、二维码 SVG 和 ZIP。
- PPTX 保持现有版本，二维码仍指向稳定视频 URL。
- 新版全部验证成功后，删除已被替代的旧视频、旧 PDF 渲染页和不再需要的录制中间文件。
- 不删除网站源码、网站素材、最终交付文件和后续维护所需脚本。

## 验收

- 本地视频可播放，编码、尺寸、帧率和音频轨道正确。
- 远程稳定 URL 返回新版视频，浏览器可读到与本地一致的时长和尺寸。
- 二维码可继续打开同一个稳定 URL。
- PDF 页数与清单一致，所有页面渲染清晰，无裁剪、黑页或重复空白页。
- ZIP 只包含最新最终交付文件。
