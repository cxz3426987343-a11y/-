# 文案类作品：文件夹工作台与作品抽屉设计

## 目标

把当前文案类占位模块改造成一个可交互的“桌面文件工作台”。访客通过六个文件夹快速进入不同文案类别，并在不离开当前页面的情况下，从右侧抽屉浏览作品图片。

整体视觉继续使用网站现有的纸张白、深绿、黄绿色体系，辅以低饱和珊瑚、蓝、黄色区分文件夹。效果应有设计感和互动感，但不持续跳动或闪烁。

## 信息架构

文案作品分为六类：

1. 新闻稿
2. 活动策划
3. 评论网宣
4. 案例萃取
5. 串词
6. 剧本脚本

素材映射：

- 新闻稿：数字记忆新闻稿.png、新闻稿2.png、新闻稿3.png
- 活动策划：元旦晚会策划1.png、元旦晚会策划案2.png、宣传片活动方案.png、活动策划1.png、活动策划2.png、活动策划3.png、综艺策划1.png、综艺策划2.png
- 评论网宣：新闻评论.png、网宣文章1.png、网宣文章2.png、评论封面.png
- 案例萃取：案例萃取-1.png、案例萃取-2.png、案例萃取3.png
- 串词：主持串词.png、纪录片解说词.png
- 剧本脚本：剧本-破茧.png、剧本-血中花.png、短视频脚本-青春日记.png、话剧直播脚本.png

页面上的作品标题优先使用图片中可识别的标题；无法稳定识别时使用整理后的文件名，不展示扩展名。

## 主页面布局

- 文案类作品作为独立作品分区，标题居中。
- 六个文件夹采用桌面图标式的不规则网格，而不是等宽卡片列表。
- 每个文件夹显示序号、中文类别和简短英文标签。
- 文件夹颜色来自网站配色系统，不使用参考图中的亮蓝色系统文件夹色。
- 使用用户提供的 React Bits Folder 结构作为基础，调整比例、层次、纸张纹理和动效。
- 悬停时文件夹轻微上浮，内部纸张展开少量；点击时完整打开并弹出右侧抽屉。
- 文件夹本身保持稳定，不做随机漂移、连续翻转或闪烁。

## 右侧作品抽屉

- 抽屉从视口右侧滑入，桌面端宽度约为视口的 48%，最大宽度约 860px。
- 页面剩余区域覆盖轻微半透明遮罩，但文件夹工作台仍然可见。
- 抽屉头部显示类别名称、作品数量和关闭按钮。
- 内容区采用双列瀑布式图片网格；窄屏改为单列。
- 每张作品显示图片和文章标题。横图按自然比例完整展示，竖图控制最大高度但不裁切正文。
- 点击普通作品后进入抽屉内的放大查看层，支持关闭、上一张和下一张。
- 切换文件夹时抽屉内容平滑替换，不关闭再重新打开。
- Escape 关闭放大层或抽屉，键盘焦点可进入文件夹和关闭按钮。

## 商业机密保护

以下六张图片必须保护：

- 案例萃取/案例萃取-1.png
- 案例萃取/案例萃取-2.png
- 案例萃取/案例萃取3.png
- 活动策划/活动策划1.png
- 活动策划/活动策划2.png
- 活动策划/活动策划3.png

保护方式：

- 图片顶部文章标题区域保持清晰。
- 标题以下区域覆盖不可通过悬停、点击或放大取消的强模糊层。
- 缩略图和放大查看层使用同一保护规则。
- 页面额外标注“内容已做保密处理”，但不暴露被模糊正文。
- 不生成或保留可从前端交互直接查看的未模糊替代版本。原素材仅作为本地源文件保留。

实现时为每张保密图片配置独立的标题清晰高度百分比，避免统一裁切导致标题被模糊或正文泄露。

## 组件边界

- CopywritingPortfolio：管理类别选择、抽屉开关、作品放大和键盘交互。
- Folder：负责单个文件夹的开合和纸张动效，不管理业务数据。
- ProtectedWorkImage：统一处理普通图片和保密图片的分层渲染。
- copywritingAssets：集中维护类别、标题、素材路径、颜色和保密区域配置。

文案模块独立于设计作品和视频作品，避免继续扩大 App.jsx。

## 动效

- 文件夹悬停：180-260ms 上浮与纸张展开。
- 抽屉进入：约 420ms，使用平滑减速曲线。
- 图片出现：小幅错峰淡入和位移。
- 放大查看：背景淡入、图片轻微缩放。
- 遵循 prefers-reduced-motion，关闭非必要位移动画。

## 响应式

- PC 端继续遵循约 1700px 版心。
- 1200px 以下文件夹改为三列。
- 760px 以下改为两列，右侧抽屉变为底部全宽面板。
- 所有标题、关闭按钮和图片不得溢出或遮挡。

## 验收标准

- 六个文件夹均可点击并打开正确类别。
- 所有 24 张素材均进入正确分类，无重复或遗漏。
- 抽屉可关闭、切换类别、放大普通图片并切换作品。
- 六张保密图片在缩略图与放大状态下均只显示清晰标题，标题以下无法看清。
- 页面无控制台错误，构建通过。
- PC 与移动端均无水平页面溢出，抽屉和文件夹交互可用。
