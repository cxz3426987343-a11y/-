# 个人作品集 Demo 互动修订方案

## 目标

将现有作品集 Demo 更新为约 110-115 秒的横屏互动演示，让招聘者通过真实的点击、悬停、滑动和页面状态变化快速理解网站结构及陈薪竹的综合能力。

本次不修改网站源代码、视觉设计、内容和功能。所有鼠标强化效果只注入录制页面，不进入生产构建。

## 视频规格

- 1920 x 1080，16:9 横屏
- 30 fps，H.264 视频，AAC 音频
- 总时长约 110-115 秒
- 删除全部后期字幕
- 保留网站自身文字和视频作品原声
- 使用低音量无歌词氛围音乐，播放视频作品时自动压低底音
- 结尾保留视频二维码，并覆盖更新到现有 Vercel Blob 稳定地址

## 鼠标互动表现

录制页面增加一个仅录制可见的鼠标指针层：

- 鼠标移动采用轻微缓动，能够看清操作方向
- 滑动页面时显示自然的移动路径，不添加持续拖尾
- 点击时出现短促的绿色扩散圆环或轻量点击反馈
- 悬停时指针保持稳定，让导航、卡片和名片动态有时间显现
- 指针不得遮挡重要标题、按钮文字或作品内容

## 视频时间线

### 1. Hero，0-8 秒

- 首屏动画正常播放
- 鼠标移动到顶部导航栏，依次经过导航项，展示导航动效
- 鼠标移动到“认识我”并点击，进入个人优势页

### 2. 个人优势，8-24 秒

- 先完整展示个人优势介绍界面，包括“HI 我是陈薪竹”、教育背景、人物照片和页面标题
- 稍作停留后点击“个人能力档案”入口
- 档案展开后快速依次点击各能力节点，展示对应说明
- 所有能力展示完毕后点击收起

### 3. 个人经历，24-34 秒

- 进入个人经历页面
- 不固定停留在单条经历
- 以舒适速度连续向下滚动，让多段经历依次进入视野

### 4. 设计类作品，34-52 秒

- 先横向移动鼠标经过不同卡片，让每张卡片的翻转或光影效果出现
- 选择“活动”类型卡片进入
- 在作品展示界面快速浏览多张作品，保留切换按钮和环绕展示效果

### 5. 视频类作品，52-68 秒

- 先横向滑动电影票，展示可选择性
- 选择第一部作品并播放一小段
- 通过暂停或鼠标移动唤出原生控件，清楚展示进度条、音量、倍速和全屏入口
- 不触发下载功能

### 6. 文案类作品，68-80 秒

- 鼠标横向经过多个文件夹，展示文件夹动态
- 点击“新闻稿”并等待纸张弹出动画完成
- 在半透明阅读栏内向下翻看一段，展示完整图片阅读方式

### 7. 运营类作品，80-101 秒

- 先展示手机锁屏
- 使用向上滑动手势解锁
- 进入小红书主页，再进入作品展示并向下翻页
- 返回应用入口，进入公众号
- 选择“笑不忘书”，进入作品展示并向下翻页

### 8. 联系页，101-110 秒

- 点击复制邮箱，展示复制成功反馈
- 点击写邮件入口，展示可跳转的邮箱选项
- 鼠标在人物 ID 卡和动漫人物卡上平滑移动，展示倾斜、流光和材质动态

### 9. 二维码收尾，110-115 秒

- 黑绿配色收尾
- 二维码不被任何文字遮挡
- 二维码指向更新后的线上 MP4

## PPT 修订

- 保持 10 页左右的横屏展示逻辑
- 全部替换为新版无字幕录屏截图
- 不使用任何带后期字幕的旧截图
- 继续沿用网站的黑、米白和绿色视觉体系
- 二维码替换为新版视频地址

## PDF 修订

PDF 不再复用 PPT 版式，改为网站静态完整展示册。

- 每页放置一个完整网页功能状态截图，不增加标题框或演示稿装饰
- 基础页面按网站顺序排列
- 个人优势需要包含介绍页和能力档案展开页
- 个人经历需要覆盖滚动过程中的主要内容
- 设计、视频、文案、运营模块需要包含入口页和关键展开状态
- 文案阅读页、运营手机各级页面和联系页需要独立截图
- 每张截图保持原始宽高比，不裁剪重要内容
- 页面数量以功能完整为准，预计 18-25 页

## 验收标准

- 视频中没有任何后期字幕
- 鼠标指针、滑动和点击反馈清晰但不抢画面
- 所有指定交互都在视频中真实发生
- 视频、PPT 和 PDF 中不出现旧字幕截图
- PDF 覆盖所有主要页面和需要点击才出现的关键状态
- 新二维码能够直接打开线上视频，服务器返回成功状态
- 网站源代码和生产部署视觉不因录制而改变
