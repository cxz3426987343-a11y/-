# 联系方式收尾页横向改版设计

## 目标

将联系方式收尾页调整为面向 PC 招聘展示的横向构图，强化人物、证件卡和联系方式之间的视觉层级，同时保留网站现有的深绿、纸白和黄绿色体系。

## 页面构图

- 页面保持整屏收尾，PC 端采用左 45% / 右 55% 的双栏布局。
- 左侧包含英文引导语、标题“期待一起创造更多可能”、电话、邮箱、复制邮箱按钮和写邮件按钮。
- 标题在标准 PC 宽度保持单行，联系信息与操作按钮压缩为紧凑的纵向信息区。
- 右侧集中展示动漫人物卡套和前层横向 ID 卡，所有人物视觉均置于版面右侧。
- 仅在窄屏手机端改为上下排列，平板和 PC 尽量维持横向关系。

## 动漫人物卡套

- 动漫人物保持完整主体并置于右后方。
- 外层增加深绿色卡套质感，包含挂孔、金属扣件、内外双层包边、压线和细微皮革纹理。
- 删除人物卡片上的 `3D CHARACTER / CXZ` 文字。
- 卡套与前层 ID 卡保留轻微错层位移，鼠标悬停时仅做克制的透视响应。

## 前层 ID 卡

- 采用横向金属证件卡形式，整体以冷银灰、淡绿反光和深绿色细节组成。
- 材质包含拉丝纹理、倒角高光、金属边框、细颗粒和随指针移动的光泽。
- 左侧证件照使用用户最新提供的原图，按接近 2:3 的原始比例贴合相框，不增加内边留白。
- 删除证件照底部绿色栏和 `CHONGQING / 01` 文案。
- 右侧重新排版姓名、电话、邮箱、生日和条码，放大信息字号并压缩无效留白。
- 重庆大学 Logo 放在卡片右上角并提高尺寸与清晰度。
- 保留卡片倾斜与流光交互，同时支持 `prefers-reduced-motion`。
- 前层 ID 卡缩小并向左下错位，仅覆盖后层人物卡套约四分之一到三分之一，形成交叠而不是大面积遮挡。
- 信息区采用高密度证件排版：姓名与生日并列，电话与邮箱纵向排列，标签和值均提高字号。

## 邮箱交互

- “复制邮箱”复制 `cxz3426987343@163.com`，成功后短暂显示“邮箱已复制”。
- “写邮件给我”不直接触发系统邮件协议，改为打开站内邮箱选择面板。
- 面板提供 163 邮箱、QQ 邮箱、Outlook 和 Gmail 四个入口。
- 点击入口后在新标签页打开对应邮箱官方网站：
  - `https://mail.163.com/`
  - `https://mail.qq.com/`
  - `https://outlook.live.com/mail/`
  - `https://mail.google.com/`
- 面板可以通过关闭按钮、点击遮罩或按 Escape 关闭，并正确处理键盘焦点。

## 导航行为

- Hero 右上角“联系我”由邮件链接改为站内按钮。
- 点击后调用现有平滑滚动逻辑，直接定位到 `#contact` 收尾页。

## 验证标准

- 在常见 PC 视口下，左侧文字和右侧人物卡片处于同一屏横向构图。
- ID 卡所有内容无重叠，证件照完整可见，Logo 清晰且尺寸合适。
- 页面无横向滚动条，移动端内容不溢出。
- 复制邮箱反馈、邮箱选择面板、四个官网链接和 Hero 联系按钮均可操作。
- 构建成功，浏览器控制台无错误。
